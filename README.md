# R4Bot

R4Bot — модульное ядро Discord-бота. Ядро отвечает за запуск, загрузку модулей, общие сервисы, конфиги, секреты, ресурсы и базовые административные команды. Пользовательский функционал подключается отдельными GitHub-модулями.

## Документация

- [Использование и администрирование](docs/usage.md)
- [Разработка модулей](docs/module-development.md)

## Что внутри ядра

- Runtime на `py-cord`.
- Загрузчик встроенных и внешних модулей.
- CLI для установки, обновления, включения, отключения, удаления и проверки модулей.
- Сервисы для конфигов, секретов, Firebase, ресурсов и состояния модулей.
- Built-in команды `/service` для базового администрирования.
- Публичный SDK для модулей: `r4bot-sdk`.

## Быстрый старт

```bash
git clone https://github.com/Rarmash/R4Bot.git
cd R4Bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Создайте `.env` по шаблону `.env_template`:

```env
TOKEN=
APPLICATIONID=
DEBUGMODE=OFF
```

Запуск:

```bash
python main.py
```

Встроенные модули ядра из `core/builtin_modules` загружаются автоматически.

После приглашения бота на сервер выполните:

```text
/service initserver
```

Команда создаст минимальный блок настроек для текущего сервера в `servers.json`.

## Модули

Установка модуля из GitHub:

```bash
python manage_modules.py install github:OWNER/REPO@master --enable
```

Обновление всех установленных модулей:

```bash
python manage_modules.py update --all
```

Обновление выполняется только если `version` в `module.json` источника выше установленной версии.

## Важное

- Установку и обновление модулей безопаснее выполнять при остановленном боте.
- Зависимости модулей хранятся в `requirements.txt` самих модулей, а не в корневом `requirements.txt` ядра.
- Секреты модулей хранятся в `config/secrets/*.json`.
- Обычные настройки модулей хранятся в `config/modules/*.json`.
- Ядро не содержит автообновления во время работы. Обновляйте ядро через Git, а модули через CLI.
